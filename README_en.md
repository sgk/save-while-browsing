# Save While Browsing

This is a Python script that automatically saves images displayed while browsing the web.
It uses Selenium and Chrome DevTools Protocol (CDP) to capture image data directly from network traffic.

## Overview

This tool automatically detects and saves images larger than a specified size during a browsing session in a specially launched Chrome browser.

**Key Features:**
*   **Auto-save**: Simply browse, and loaded images are automatically saved.
*   **Size Filter**: Specify a minimum size to exclude small icons or thumbnails (default: 480x320).
*   **Filename Normalization**: Generates filenames from URLs and safely converts them to avoid issues on Windows (CP932).

## Setup

### Requirements
*   Python 3.x
*   Google Chrome

### Installation

1.  Clone the repository.
    ```bash
    git clone https://github.com/sgk/save-while-browsing.git
    cd save-while-browsing
    ```

2.  Install dependencies.
    ```bash
    pip install -r requirements.txt
    ```

## Usage

When you run the script, a Chrome browser will launch. Browse sites where you want to save images using that browser.

```bash
python save-while-browsing.py [archive_dir] [--min WIDTHxHEIGHT]
```

### Arguments
*   `archive_dir` (Required): Path to the directory where images will be saved. It will be created automatically if it doesn't exist.
*   `--min` (Optional): Minimum size of images to save in `WIDTHxHEIGHT` format. Default is `480x320`.

### Example

To save images in the `my_images` folder and filter for images larger than `800x600`:

```bash
python save-while-browsing.py my_images --min 800x600
```

To exit, press `Ctrl+C` in the terminal.

## Mechanism

1.  **Launch Browser**: Uses Selenium to launch a Chrome browser with an independent profile.
2.  **Network Monitoring**: Enables the `Network` domain of the Chrome DevTools Protocol (CDP) to monitor all network traffic generated by the browser.
3.  **Image Detection**: Detects responses with MIME types starting with `image/` in the `Network.responseReceived` event.
4.  **Data Retrieval**: When image loading is complete (`Network.loadingFinished`), retrieves the response body (image data) using the `Network.getResponseBody` command.
5.  **Filtering and Saving**: Expands the retrieved data in memory and checks the image size using Pillow. Saves to disk only if it meets the specified conditions (`--min`).

## Notes
*   This tool creates a directory named `.chrome` in the current directory to use as the browser profile.
